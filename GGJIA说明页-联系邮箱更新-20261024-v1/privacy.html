GGJIA Keyword Monitor 隐私政策

本政策说明 GGJIA Keyword Monitor（GGJIA 关键词监控台）如何访问、使用、存储和公开数据，适用于当前版本的监控工具。运营联系邮箱：2529217349@qq.com。

1. 访问的数据与用途

运营者授权后，程序读取 Google 账号邮箱以核对初始化身份，读取该账号可访问的 Search Console 属性清单以找到 GGJIA 属性，并采集 GGJIA 网站的搜索查询、页面地址、日期、点击、展示、点击率和平均排名。采集口径为美国、全部设备、网页搜索。这些数据用于页面与关键词查询、周月对比、分析说明及导出。

程序还读取 GGJIA 的公开 Sitemap，并使用既有关键词监控资料补充页面清单和历史基线。Search Console 数据是 Google 返回的统计数据，不包含搜索者身份，且可能存在匿名查询、延迟和行数限制。

2. Google 权限的用途

  • 账号邮箱：核对初始化操作是否由指定运营者发起。
  • Search Console 只读权限：读取 GGJIA 搜索表现，不修改网站属性或提交网站变更。
  • Drive 文件级权限（drive.file）：创建和读写本应用使用的专用 Google 表格，不请求全账号表格访问权限。
  • 连接外部服务：请求 Google API 和 GGJIA 的公开 Sitemap。
  • 脚本触发器权限：安装和维护本应用的定时采集任务。

3. 存储与保留

采集记录、任务和日志存储在运营者账号下的专用 Google 表格；表格保持私有。运行配置存储在 Apps Script 脚本属性中，Google 授权由 Google 的机制管理。监控台不会把访问令牌或私有表格地址返回给普通访问者。

当前版本最初回填约 95 天的逐日数据，并持续采集后续数据；95 天不代表自动删除期限。已存历史保留至运营者主动清理。部分既有基线资料随应用部署保留，需要更新部署才能移除。

新导入的 Semrush 文件由当前浏览器解析，导入记录存储在该浏览器的 IndexedDB／本地存储，不由此功能自动上传到云端。清理该站点的浏览器数据会删除本地导入记录。应用预置的既有 Semrush 基线随部署公开提供，与新导入文件区分。

4. 公开展示与服务提供方

运营者选择免登录公开展示。任何获得监控台链接的人都可以查看和下载公开响应中的 GGJIA 页面、关键词、流量与排名指标、周月对比、研究记录、资料来源信息和运行状态；免登录数据接口提供同样的公开监控内容。公开展示不等同于开放后台表格编辑权限。

Google 为本工具提供授权、计算和存储服务。工具不出售 Google 用户数据，不将其用于广告定向、信用评估或训练通用人工智能模型。Google API 数据仅用于本工具明确展示的运营功能及运营者选择的公开监控展示；相关处理须遵守 Google API Services User Data Policy，包括适用的 Limited Use 要求。

5. 停止采集与删除

运营者可以在 Apps Script 中删除采集触发器，并在 Google 账号的第三方连接设置中撤销本应用授权，停止后续采集。撤销授权不会自动删除已存历史，也不会自动关闭仍可读取的历史展示。

如需停止公开展示，应先停用网页部署，再删除专用表格，并清理应用中的历史基线及相关脚本属性。可通过联系邮箱申请协助。已经由其他访问者下载或另存的公开副本无法由本应用远程删除。

6. 访问页面及政策更新

监控台使用浏览器存储保存本地导入资料和显示设置。Google 托管监控台，GitHub Pages 托管本说明站。访问 GitHub Pages 时，GitHub 会为安全目的记录访问者的 IP 地址；相关服务也可能按各自政策处理访问日志或 Cookie。本说明站不包含 GSC 原始报表、Google 访问令牌或云端表格的私有地址。本政策不替代这些平台的其他政策。数据处理方式发生变化时，应先更新本政策；需要新增授权时，由运营者重新确认。
